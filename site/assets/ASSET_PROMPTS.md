# Visual asset provenance

The raster hero background was generated with the built-in image generation tool and then
copied into this repository as `hero-atlas.webp`. Text, metrics, the brand mark, the
architecture diagram, the README poster, and the Open Graph card are rendered from local
HTML/CSS/SVG so they remain editable and testable.

## Final image prompt

```text
Use case: stylized-concept
Asset type: wide landing-page hero background for an open-source epidemiological intelligence research harness
Primary request: create an editorial scientific control-room abstraction showing a dark world atlas built from fine contour lines, a few precise outbreak evidence nodes connected by thin audit trails, translucent data ledgers, and one luminous controlled experiment loop moving through the composition
Scene/backdrop: near-black ink field with subtle paper grain and technical grid, no literal hospital scene and no people
Style/medium: premium editorial data visualization fused with screen-printed scientific poster art; restrained, tactile, rigorous, not glossy corporate 3D
Composition/framing: very wide landscape, strongest detail on the right two-thirds, generous dark negative space on the left for webpage headline; layered depth but clean silhouette
Lighting/mood: nocturnal observatory, calm vigilance, methodical and trustworthy rather than alarming
Color palette: deep charcoal and black, cyan-blue evidence signals, safety orange warnings, electric chartreuse accepted paths, warm off-white fine lines
Materials/textures: archival paper grain, ink, etched map contours, subtle glass overlays
Constraints: no text, no letters, no numbers, no logos, no watermark, no medical crosses, no syringes, no biohazard symbols, no photorealistic viruses, no purple gradient, no generic AI robot imagery
```

Generated on 2026-08-13. The bundled image is an aesthetic project asset, not epidemiological
data and not a geographic visualization of real outbreaks.
